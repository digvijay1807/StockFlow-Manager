# StockFlow Manager

A Python-based desktop application for managing inventory, billing, and sales using Tkinter and SQLite.

## Features
- Employee management system
- Supplier tracking
- Product and category management
- Billing system with calculator
- Sales history tracking

## Tech Stack
- Python
- Tkinter (GUI)
- SQLite (Database)
- PIL (Image handling)

## Setup Instructions
1. Run `create_db.py` first to initialize database
2. Run `dashboard.py` to start the application
3. Ensure `images/` and `bill/` folders exist

## Note
This project is customized and extended for learning and academic purposes.
